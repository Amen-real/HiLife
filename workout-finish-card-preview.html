这次改了什么

  • 入口不变：顶栏还是那颗亮绿「完成训练」bindtap="finishWorkout"，只是它现在开卡片。
  • 出口从「保存 / 干脆直接保存」变成三个有名字的出口：全完成 → 直接 saveWorkout → 完成并生成分享图 / 完成训练 / 取消。
  • 未完成组的确认不再用系统框：wx.showModal「还有未完成组，确定保存当前进度？」 → 卡片副标题「还有 N 组未完成」+ 本场摘要（一次确认，不弹两次）。
  • 「完成并生成分享图」= 保存后 redirectTo 到复盘页并自动打开分享卡： 用 redirectTo 而不是 navigateTo，训练页已结束就替换掉， 从复盘页返回直达训练 tab，不会退回一张空训练页。
  • 分享路径的 toast 停留 1000ms → 700ms（用户的目标就是那张图）。
  • 参考图里的「写入 Apple 运动健康」开关 没有照搬：本 App 没有这条能力，按项目红线不摆假开关， 那个位置换成本场摘要（已练 / 完成组数 / 完成动作，三个都已发生的事实）。

顺带修掉的一个真机 bug（深色主题下）

  • 组间休息的「训练完成」绿底徽章里，奖杯图标用的是 .ico--ink（取 var(--text)）： 深色主题把 --text 翻成 #FFFFFF，而徽章底色是固定的品牌亮绿 → 白字形压亮绿 ≈1.6:1，真机上那个奖杯直接看不见。
  • 修法：.rest-pop-emoji.solid .ico { background-color: #0A0A0A } —— 绿底与主题无关，字形也必须与主题无关。 新守卫 verify-icon-contrast.cjs [H] 拦这类回归。

未登录时

  • 点「完成并生成分享图」但未登录 → 不保存、也不关卡片（什么结果都没发生，卡片就不该凭空消失）， 走原来的登录引导弹窗。
这份预览的保真边界（不撒谎）：
· 换算比例 1rpx = 0.52px（390px 屏宽），画布 390×844，卡片与顶栏的尺寸/圆角/间距全部由 workout.wxss 逐条换算，颜色令牌照搬 app.wxss，深色帧只重定义变量。
· 背景页是简化示意：真实动作卡带 GIF 缩略图、展开态与更多字段，这里只画了轮廓用于给卡片定位；卡片本体是完整的。
· 奖杯图标在真机走 mask-image + SVG data-URI（本预览用的是同一个 data-URI），字形色由 background-color 决定 —— 与真机机制一致，所以深色帧里奖杯是否可见可以直接信这一帧。
· 真机还叠加自定义 tabBar 与吸顶导航栏；卡片是 z-index:100 的居中遮罩，不受它们影响。
