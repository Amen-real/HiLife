# 1.1 版本规划：存储拆键 · 分享卡带码 · 周报

> 拍板记录（2026-10-19）：**不做云同步**（隐私口径「只存本机」维持不变）；14-plan-rotation 作废（模板自动轮转已被现有功能覆盖）。
> 本版范围 = **A 存储拆键（保命）＋ E 分享卡带码（裂变）＋ 周报（主功能）**。
> 排序原则：T1 最先（数据读取路径变更影响后续所有步骤），T2 独立可插，T3→T6 串行。

## T1 本地存储拆键（保命项，先行）

### 现状（已核对源码）
- `app.js persist()`：**全量 globalData 落单键 `uu_fitness_state`**；写失败已接住＋节流提示一次。1MB 上限，trainingLogs/meals 只增不减。
- **`uu_fitness_backup`（logout 快照）同样是全量单键**——拆键必须连它一起处理，否则退出登录时照样撞 1MB。
- 导出备份走 `profile.js` 的 `DATA_KEYS` 聚合，格式独立于 storage 键结构。

### 方案
1. **月拆键**：`trainingLogs` → `uu_fitness_log_YYYY_MM`；`meals` → `uu_fitness_meal_YYYY_MM`。主键 `uu_fitness_state` 只存小对象（profile / weightRecords / trainingPlans / favorites / activePlanId / selectedActions / keyActionPicks / customActions / userInfo / reminderDismissedOn）＋ **月键索引** `logMonths: ['2026_09','2026_10']`。
2. **读取**：启动只载入近 3 个月进 globalData；更早月份**懒加载**（列表/复盘翻到时按月 `getStorageSync`，单月远小于 1MB）。
3. **写入**：当月数据照旧改 globalData → persist 时把当月两键单独写＋索引更新；历史月键**只读**（理论上旧月不再新增）。
4. **迁移**（首次启动）：检测旧键 → 按月拆分写入 → **条数守恒校验** → 旧键改名 `uu_fitness_state_migrated` 保留一个版本 → 下下次启动清除。迁移函数必须**幂等**（跑两次结果一致）。
5. **logout 快照瘦身**：`uu_fitness_backup` 改存「小对象＋月键索引」——月键本来就在 storage，退出只需重置 globalData 内存态，登录恢复时按索引读月键。

### 校验与守卫
- 迁移**幂等性**探针（node stub wx storage，跑两次全等）。
- **条数守恒**：拆分前后 trainingLogs/meals 每条都在（按 id 断言）。
- 单月键体积压测：脚本造 500 场训练日志塞进一个月，确认远离 1MB。
- 既有守卫全绿（verify-date-range-boundary 等 24 个）；跨月周的懒加载读取正确性并入 T3 测试。
- 真机迁移演练：旧版本造数据 → 升级打开 → 全量数据可查可导出。
- ⚠️ 教训带入：探针 stub `wx` 的 `setStorageSync` 必须真模拟容量上限与同步语义；stub `Page` 跑**真实处理器**。

## T2 分享卡带小程序码（小而独立）

- 方案：**固定码**（现有压缩版二维码）叠到分享卡固定位置（白底圆角托底，右下角），生成时直接 `drawImage` 叠加——零服务端、零 API 成本。动态带参码（scene 归因）留 1.2。
- 实现前核对：分享卡当前生成机制（canvas 尺寸/坐标）——「分享卡禁重算」口径不变，只叠图不改数据。
- 校验：码白底托底在深浅两主题下都可扫；不遮名称/热量等关键字段；真机对卡片截图长按识别成功。

## T3 周报数据层（纯函数）

- 扩展 trainingStats 或新建 `utils/weeklyReport.js`：`weeklyReport(logs, meals, weightRecords, weekStart)` 输出——训练次数/总时长/总容量/RPE 均值、体重起止与差值、饮食记录天数与日均 kcal（对照每日推荐）。
- **单源约束**：自然周一律走 `dateRange.js`（周一 00:00 起、半开区间）；TDEE/推荐值复用 kcal 既有口径，禁第二份实现。
- 守卫：跨月周（周一半在上月）的懒加载拼接正确性；node 探针直测纯函数。

## T4 周报视觉稿（HTML 确认后再动代码）

- 仓库根新增 `16-weekly-report.html`（按老流程：设计稿确认 → 转小程序页）。
- 主包体积预算：新页 ≈ 30KB 内（当前余量 433KB，无虞）；深色主题三件套按红线。

## T5 周报页实现

- 新页 `pages/weekly/`；入口挂在「复盘」或「我的」（视觉稿定）；当前周为默认视图＋左右切周。

## T6 周报分享卡 ＋ 收尾
