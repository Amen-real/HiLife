这次改了什么（逐条）

  • 导入入口：模板弹层新增主 CTA 「导入整套计划」（亮绿底 + #0A0A0A 字），副标显示 3 个训练日 · 每周 3 次 · 完成后自动轮换；原「导入此训练日」降级为灰底次级按钮，多训练日模板改写「设为今日」。
  • 计划卡片：力量·基础五大项 · A 日 · 下肢推 + 上肢推 → 标题只留训练日 A 日 · 下肢推 + 上肢推，上方新增一行模板组名（同组仅首卡显示），A / B / C 一眼可辨。
  • 卡片顺序：按 active 单个置顶（A,B,C → B,A,C） → 激活模板组整体置顶、组内恒按 A→B→C，「今日」由卡片标签标识，不再靠位置。
  • 本周目标：导入模板后无 daysPerWeek，兜底 5 → 取模板 daysPerWeek，力量模板即 0/3 起（增肌·推拉腿为 0/6）。
  • 轮转：训练保存后 store.advanceActivePlan() 推进今日计划指针，A → B → C → A 循环；仅计划流生效（手动勾选动作流不轮转），单训练日模板不轮转。
  • 首页今日推荐：标题 = 完整计划名（力量·基础五大项 · B 日 · 髋铰链 + 上肢拉，两行折行） → 标题 = B 日 · 髋铰链 + 上肢拉，副标 = 模板名 · N 个动作 · 约 M 分钟。
  • 模板计划补齐 goal / level / daysPerWeek，卡片与详情页的「力量 / 中级」标签随之出现（此前模板计划不写 goal，标签行整行缺失）。
备注：HTML 里的图标用字符/方块示意 —— 真机图标走 styles/icons.wxss 的 mask-image + data-URI（<image> 不认 SVG data-URI）。 tabBar 为简化示意，真机为 custom-tab-bar 隔离组件（含药丸动效）。切页动效、下拉刷新等动态行为未在静态帧中体现。
